# Foodgram

Foodgram — сервис для тех, кто любит готовить и делиться рецептами. Здесь можно
находить новые блюда, следить за публикациями любимых авторов, сохранять
понравившиеся рецепты и удобно планировать покупки продуктов.

## Возможности

- просмотр подробных рецептов с фотографиями и пошаговым описанием;
- фильтрация блюд по тегам;
- публикация и редактирование собственных рецептов;
- сохранение понравившихся рецептов в избранное;
- подписка на любимых авторов;
- добавление блюд в список покупок;
- скачивание готового перечня ингредиентов с подсчитанным количеством;
- настройка профиля и аватара.
